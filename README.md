# 🧠 FlashStudy AI — Flashcard & Quiz Hub

An interactive web application built with HTML, CSS (Tailwind), and JavaScript. Feature-rich flashcard study hub with 3D card flips, progress tracking, deck creation, and JSON data export.

---

## ✨ Features

- **3D Card Flip Animation:** Smooth CSS 3D perspective transforms to reveal answers.
- **Mastery Tracking:** Rate cards ("Needs Review" vs. "Mastered") to see dynamic deck completion percentages.
- **Custom Flashcard Creator:** Add your own flashcards and categories via an interactive modal.
- **JSON Data Export:** Download your custom decks to backup or share.
- **Local Persistence:** Saves all cards and mastery scores directly in `localStorage`.
